راهنمای افزودن تصاویر واقعی (Real Image Guide)
================================================

پوشه‌ی assets/images/gallery/ برای تصاویر نمونه‌کارهای گالری در نظر گرفته شده.
کافیست عکس‌های خودتان را دقیقا با همین نام‌ها در این پوشه قرار دهید تا به‌صورت
خودکار جایگزین پس‌زمینه‌های بنفش تزئینی فعلی شوند:

  logo-01.jpg   logo-02.jpg   logo-03.jpg
  poster-01.jpg poster-02.jpg poster-03.jpg
  card-01.jpg   card-02.jpg

همچنین دو تصویر زیر را برای سئوی بهتر (شبکه‌های اجتماعی و آیکون موبایل) اضافه کنید:

  og-cover.jpg          -> تصویری که هنگام اشتراک‌گذاری لینک سایت نمایش داده می‌شود (1200x630)
  apple-touch-icon.png  -> آیکون سایت برای صفحه اصلی موبایل اپل (180x180)

اگر تصویری وجود نداشته باشد، طراحی به‌صورت خودکار از گرادیان بنفش نئونی و
آیکون جایگزین استفاده می‌کند، بنابراین سایت هرگز عکس شکسته نشان نمی‌دهد.
